# El Chalan

Set the auditor intensity to one of these modes: `godin` is low, fast, and pragmatic; `chakaloso` is medium, focused, and critical; `chambeador` is high and exhaustive; `off` disables the overlay. Apply the selected mode only to `elmatamuertos` and `elmatachingaderas`, never `elmatabichos`. Use the selected mode for later auditor commands in this conversation.
