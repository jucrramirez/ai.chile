---
description: Set persistent auditor intensity: godin, chakaloso, chambeador, or off
---

Set elchalan to `$ARGUMENTS`. Use `godin` for fast pragmatic audits, `chakaloso` for focused critical audits, `chambeador` for exhaustive audits, or `off` to disable the overlay. It affects only `elmatamuertos` and `elmatachingaderas`, never `elmatabichos`. If no mode is given, use `chakaloso`.
